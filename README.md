# SWARM-Store **RU** | [EN](README.EN.md)

Официальный репозиторий модулей и тем для [SWARM](https://github.com/FreshLend/SWARM).

Этот репозиторий служит центральным хабом, откуда можно просматривать, скачивать и устанавливать расширения для своей десктопной среды SWARM напрямую через встроенный модуль Store.

### Модули
Модули должны размещаться в директории `modules`. Вы можете создавать любые папки категорий для их удобной сортировки.

Требуемый формат пути:
`modules/<категория>/<имя_модуля>/`

Внутри папки `<имя_модуля>` обязательно должны быть:
*   `metadata.json` (должен содержать как минимум: `name`, `version`, `author`, `description`).
*   `module.py` (основной класс модуля).
*   *(Опционально)* `icon.svg` или `icon.png`.
*   *(Опционально)* Папка `langs` с файлами переводов.

### Темы
Темы должны размещаться в директории `styles`, следуя той же логике категоризации.

Требуемый формат пути:
`styles/<категория>/<имя_темы>/`

Внутри папки `<имя_темы>` обязательно должны быть:
*   `theme.json` (должен содержать как минимум: `name`, `version`, `author`).
*   `style.qss` (шаблон стилей Qt).

## Свои репозитории

Если вы разрабатываете собственные модули и хотите протестировать их или поделиться с определенным кругом лиц, вам не нужно создавать Pull Request в этот репозиторий.

Вы можете создать свой собственный репозиторий на GitHub, соблюдая описанные выше правила путей. Затем в модуле SWARM Store просто нажмите **Доб. репозиторий**, введите имя вашего репозитория в формате `owner/repo`, и он появится в вашем магазине.
